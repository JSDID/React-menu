# React Menu

Меню для лендинга на React 

## Особенности
- Мобильная версия с бургер-иконкой
- Плавная анимация открытия/закрытия мобильного меню

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <your-repo-url>
   cd React-menu
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите проект:
   ```bash
   npm run dev
   ```

4. Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## Структура проекта

- `src/App.jsx` — основной компонент приложения
- `src/components/Menu` — компонент меню 

## Кастомизация

- Для изменения пунктов меню — редактируйте массив `menuLinks`.
- Для замены логотипа — положите свой файл в `public/` и обновите путь в компоненте.
