# React Menu

Многоуровневое меню для лендинга на React 

## Особенности

- Современный стек: React + Vite
- Меню с кнопкой "Каталог товаров" и ссылками
- Мобильная версия с бургер-иконкой
- Плавная анимация открытия/закрытия мобильного меню
- Легко настраиваемые пункты меню

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone <your-repo-url>
   cd React-menu
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите проект:
   ```bash
   npm run dev
   ```

4. Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## Структура проекта

- `src/App.jsx` — основной компонент приложения
- `src/Menu.jsx` — компонент меню (создайте, если ещё нет)
- `src/Menu.css` — стили для меню
- `public/` — статические файлы (логотип и т.д.)

## Кастомизация

- Для изменения пунктов меню — редактируйте массив `menuLinks` в `App.jsx` или `Menu.jsx`.
- Для замены логотипа — положите свой файл в `public/` и обновите путь в компоненте.
